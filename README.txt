CAMPUS PULSE - BEGINNER STARTER WEBSITE

FILES
- index.html: page structure
- style.css: page design
- script.js: map, room status, issue report and admin demo logic
- data.json: sample building and room information

HOW TO RUN
1. Open the Campus-Pulse folder in Visual Studio Code.
2. Install the "Live Server" extension by Ritwick Dey.
3. Right-click index.html.
4. Choose "Open with Live Server".
5. Your browser should open the website.

IMPORTANT
- Internet is required for the Leaflet library and OpenStreetMap tiles.
- The building marker coordinates are approximate demo positions.
  Replace them with verified coordinates from an official campus map.
- This is a front-end class-project prototype. The admin controls are
  not protected by a real login and browser storage is local to one browser.
- GitHub Pages can publish this static website. Upload all four main
  website files (index.html, style.css, script.js, data.json).
